# Phase 1 — UI Design Contract: Chat Widget

> Visual and interaction contract for the floating chat button and panel component.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property             | Value                                            |
| -------------------- | ------------------------------------------------ |
| Tool                 | none — custom CSS tokens                         |
| Preset               | not applicable                                   |
| Component library    | none (native HTML + Tailwind v4)                 |
| Icon library         | inline SVG (no external icon lib)                |
| Font (display)       | Fraunces, Georgia, serif (`var(--font-display)`) |
| Font (mono / labels) | IBM Plex Mono, ui-monospace (`var(--font-mono)`) |

Source: `src/index.css` @theme block. Do NOT hardcode hex values — always use `var(--color-*)` tokens so dark/light theme works automatically.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage                                                                                      |
| ----- | ----- | ------------------------------------------------------------------------------------------ |
| xs    | 4px   | Icon gaps, inline icon padding                                                             |
| sm    | 8px   | Chip pill padding (horizontal), message bubble internal padding                            |
| md    | 16px  | Panel header/footer padding, message list padding                                          |
| lg    | 24px  | Panel internal vertical rhythm                                                             |
| xl    | 32px  | Panel gap from viewport edge (`bottom: 24px right: 24px` → button; panel anchors above it) |
| 2xl   | 48px  | Not used in this phase                                                                     |
| 3xl   | 64px  | Not used in this phase                                                                     |

Exceptions:

- Chat button touch target: 56px diameter (minimum, per CONTEXT.md decision; max 64px). This is intentionally off the standard 4-pt scale to hit accessible touch target size.
- Panel: fixed 380px wide × 560px tall. Not responsive — site has ScreenGuard for mobile (requirement out of scope per REQUIREMENTS.md).

## Typography

All type inherits from `src/index.css` base rules. The chat component must not introduce new font sizes outside this table.

| Role               | Font Stack                         | Size | Weight      | Line Height | Usage                               |
| ------------------ | ---------------------------------- | ---- | ----------- | ----------- | ----------------------------------- |
| Panel header title | `var(--font-display)`              | 16px | 400, italic | 1.2         | "Ask Karl" header label             |
| Message body       | `var(--font-body)` (Fraunces)      | 15px | 400         | 1.5         | AI and user message text            |
| Chip / label       | `var(--font-mono)` (IBM Plex Mono) | 11px | 400         | 1.4         | Suggested prompt chips, send button |
| Meta / helper      | `var(--font-mono)`                 | 11px | 400         | 1.4         | Placeholder text, input hint        |

Two weights declared: 400 (regular) for all roles. No semibold/600 needed — the editorial system uses italic style rather than weight variance for hierarchy.

Source: Established site pattern from `src/index.css` (.label class at 11px, body at 16px, .about\_\_cols p at 15px).

## Color

All values are CSS custom properties that resolve correctly in both light and dark themes automatically. Do NOT hardcode hex.

| Role            | Token                                  | Light resolves to                | Dark resolves to                     | Usage                                                  |
| --------------- | -------------------------------------- | -------------------------------- | ------------------------------------ | ------------------------------------------------------ |
| Dominant (60%)  | `var(--color-bg)`                      | `#f7f3ec`                        | `#14110d`                            | Panel background surface                               |
| Secondary (30%) | `var(--color-fg-2)` / hairline borders | `#2a2a2a` / `rgba(10,10,10,0.1)` | `#d8d0be` / `rgba(243,234,216,0.14)` | Message bubbles (AI), borders, input area              |
| Accent (10%)    | `var(--color-fg)`                      | `#0a0a0a`                        | `#f3ead8`                            | Chat button bg, user message bubble bg, send button bg |
| Muted text      | `var(--color-fg-3)`                    | `#6b6b6b`                        | `#8a8278`                            | Placeholder, chip border color, loading dots           |
| Destructive     | not applicable                         | —                                | —                                    | No destructive actions in this phase                   |

Accent (`var(--color-fg)`) reserved for:

1. Floating chat button background
2. User message bubble background (user bubble = fg bg + bg-colored text for inversion)
3. Send button background when input is non-empty

AI message bubble: `var(--color-bg)` background with `1px solid var(--color-hairline)` border — subtle, sits on panel surface.

User message bubble: `var(--color-fg)` background, `var(--color-bg)` text — hard inversion, matches site's `::selection` pattern.

Source: CONTEXT.md ("Color: `--color-fg` background, `--color-bg` icon — adapts automatically to dark/light theme toggle"), `src/index.css` ::selection pattern.

## Component Inventory

### `ChatBot.tsx` — root component

**Floating button:**

- Shape: circle, 56px × 56px (use `w-14 h-14` = 56px)
- Position: `fixed bottom-6 right-6` (24px from edges)
- Background: `var(--color-fg)`, icon color: `var(--color-bg)`
- Icon: chat bubble SVG when closed, × (close) SVG when panel is open
- Transition: icon swap with 200ms opacity fade
- Accessibility: `aria-label="Open chat"` / `"Close chat"` toggled on state

**Chat panel:**

- Position: `fixed bottom-24 right-6` (anchored above button, 96px from bottom)
- Dimensions: `w-[380px] h-[560px]` fixed
- Background: `var(--color-bg)`
- Border: `1px solid var(--color-hairline)`
- Border radius: 8px (`rounded-lg`)
- Shadow: `box-shadow: 0 8px 32px rgba(0,0,0,0.12)` — lightweight, editorial
- Animation: open → `translateY(0) opacity(1)` from `translateY(16px) opacity(0)`, duration 220ms ease-out; close is reverse

**Panel header (row, 48px tall):**

- Left: title "Ask Karl" in `var(--font-display)`, 16px, italic, weight 400, `var(--color-fg)`
- Right: × close button, 32px tap target, `var(--color-fg-3)` default, `var(--color-fg)` on hover, `aria-label="Close chat panel"`
- Bottom border: `1px solid var(--color-hairline)`
- Padding: 16px horizontal

**Message list (scrollable, fills remaining height):**

- Overflow: `overflow-y: auto`, auto-scrolls to bottom on each new message
- Padding: 16px all sides, 8px gap between message bubbles
- Scrollbar: default browser scrollbar (no custom styling)

**Message bubble — AI:**

- Alignment: left (flex-start)
- Max width: 85% of panel width
- Background: `var(--color-bg)`, border: `1px solid var(--color-hairline)`
- Border radius: `rounded-lg` (8px), with bottom-left corner squared: `rounded-bl-sm` (2px)
- Padding: 8px 16px
- Font: `var(--font-body)`, 15px, weight 400, line-height 1.5

**Message bubble — User:**

- Alignment: right (flex-end)
- Max width: 85% of panel width
- Background: `var(--color-fg)`, text: `var(--color-bg)`
- Border radius: `rounded-lg` (8px), with bottom-right corner squared: `rounded-br-sm` (2px)
- Padding: 8px 16px
- Font: `var(--font-body)`, 15px, weight 400, line-height 1.5

**Loading indicator (inside AI bubble):**

- Three dots, 6px diameter circles, `var(--color-fg-3)` fill
- Animation: staggered pulse (0ms / 150ms / 300ms delay), scale 0.6→1→0.6, duration 800ms infinite
- Sits inside an AI message bubble that appears immediately when request is in-flight

**Suggested prompt chips (shown only before first message):**

- Layout: horizontal flex-wrap, 8px gap, centered in message area
- Each chip: pill shape, `border: 1px solid var(--color-hairline)`, `var(--color-bg)` bg
- Chip hover: border upgrades to `var(--color-fg)`, no bg change
- Font: `var(--font-mono)`, 11px, `tracking-[0.10em]`
- Padding: 8px 16px
- Border radius: 999px (full pill)
- Four chips — exact labels locked:
    1. "Who are you?"
    2. "What do you build?"
    3. "What are you working on?"
    4. "How can I reach you?"

**Panel footer (input row, 56px tall):**

- Top border: `1px solid var(--color-hairline)`
- Padding: 8px 16px
- Input: plain `<input type="text">`, no border, no outline, bg transparent, `var(--font-body)` 15px, `var(--color-fg)` text, `var(--color-fg-3)` placeholder
- Send button: 36px × 36px, circle, `var(--color-fg)` bg when enabled, `var(--color-hairline)` bg when disabled, `var(--color-bg)` icon, border-radius 50%
- Send button icon: right-pointing arrow SVG (inline)
- Send button disabled state: `opacity-50 cursor-not-allowed`
- Input disabled while loading: `opacity-60` on the entire footer row

## Interaction States

| State                      | Trigger                 | Visual Change                                                       |
| -------------------------- | ----------------------- | ------------------------------------------------------------------- |
| Button idle                | Default                 | `var(--color-fg)` circle, chat bubble icon                          |
| Button hover               | Mouse over              | `opacity-90` (subtle — no transform to stay editorial)              |
| Button active (panel open) | Click                   | Icon swaps to ×                                                     |
| Panel enter                | Button click            | `translateY(16px)→0` + `opacity(0)→1`, 220ms ease-out               |
| Panel exit                 | Close click or × button | Reverse, 180ms ease-in                                              |
| Chip hover                 | Mouse over chip         | Border color upgrades to `var(--color-fg)`                          |
| Chip click                 | Click                   | Chip area disappears, message sent immediately                      |
| Loading                    | API call in-flight      | Pulsing 3-dot bubble appears, input row `opacity-60`, send disabled |
| Error                      | API failure             | Error bubble appears: "Something went wrong. Try again."            |
| Send disabled              | Input empty             | Send button `opacity-50 cursor-not-allowed`                         |
| Send enabled               | Input non-empty         | Send button full opacity                                            |
| Input submit               | Enter key or send click | Input clears, user bubble appears, loading state starts             |

## Accessibility Contract

- Chat button: `aria-label` toggled between "Open chat" and "Close chat"
- Panel header × close button: `aria-label="Close chat panel"` (icon-only button requires explicit label)
- Panel: `role="dialog"` with `aria-label="Chat with Karl's AI assistant"` and `aria-modal="true"`
- Message list: `aria-live="polite"` so screen readers announce new messages
- Send button: `aria-label="Send message"` + `disabled` attribute when empty
- Input: `aria-label="Type your question"` + `disabled` attribute while loading
- Focus management: focus moves into input when panel opens; focus returns to button when panel closes
- Reduced motion: panel animation skipped when `prefers-reduced-motion: reduce` (matches existing site pattern in `src/index.css`)
